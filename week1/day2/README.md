1. What is Salesforce Platform?
Salesforce Platform is a cloud-based platform used to build and manage business applications without needing heavy hardware or software installation. It helps companies store customer data, automate business processes, create apps, generate reports, and improve communication between teams.
Salesforce mainly works on the concept of CRM (Customer Relationship Management). It allows users to manage sales, service, marketing, and other business activities in one place. Since it is cloud-based, users can access the system from anywhere using the internet.
The platform also provides tools for:
Creating custom applications
Managing databases
Automating workflows
Building dashboards and reports
User security and access control

2. Explain
App :
In Salesforce, an App is a collection of tools, tabs, objects, and features grouped together for a specific purpose. It helps users access related functionalities from one place.
For example:
Sales App
Service App
Student Management App
An app makes navigation easier because users can work with all required modules inside one application.

Object :
An Object in Salesforce is similar to a database table. It stores information in the form of records and fields.
Examples:
Student Object
Employee Object
Each object contains:
Fields → store data
Records → individual entries
Example:
A Student object may contain:
Student Name
Roll Number
Branch
Phone Number
Tab :
A Tab is used to access objects, records, dashboards, or applications in Salesforce. Tabs appear on the navigation bar and help users open different sections quickly.
For example:
Accounts Tab
Contacts Tab
Student Tab

App
Student Management App
This app is used to manage student details, courses, and attendance information.

Objects Used
1. Student Object

Student ID
Name

Email
2. Course Object
